Golden Ticket prize builder

Set up the prize page in five steps. Everything happens on this computer: nothing you type here is sent anywhere.

1About your sale

These details appear on the prize page and on the printed tickets.

2Ticket codes

Every golden ticket needs a number and a secret reference code. Winners type both into the prize page.

You’ve already saved a set of codes. New codes won’t match any tickets printed from the old ones.

Download the spreadsheet now and keep two copies somewhere private (not on the website). It is the only record of which code belongs to which ticket. Lose it, and the printed tickets can’t be matched to prizes.

Make a spreadsheet with one row per ticket: its number and its reference code, exactly as printed. This blank one has the right columns.

Print the golden tickets

Ten tickets to an A4 page, each 9 × 5 cm, with the number, reference code and a QR code that opens the prize page with the details filled in.

Make and download codes first (or load a saved spreadsheet in step 3).

3Add the prizes

  1. Open the spreadsheet in Excel, Numbers or Google Sheets.
  2. Type a prize in the Prize column for every ticket. The other columns are optional.
  3. Save it as CSV. In Excel: File › Save As › CSV UTF-8. In Google Sheets: File › Download › CSV.
  4. Load it here.

    4How winners get their prizes

    Winners see these instructions after the reveal. Set collection prize by prize in the spreadsheet; this default covers any you left blank.

    5Build the prize file

    This scrambles every prize so it opens only with its own ticket number and code, then checks each ticket opens. It takes a few seconds.

    Then

    1. Upload prizes.js to your website, next to index.html and core.js, replacing the old one.
    2. Open the prize page and try two or three real tickets before they go into the bars.
    3. Keep the spreadsheet private. Never upload it.
